# Poultry Recognition and Management System

A computer-vision research and prototyping repository focused on poultry recognition, with experiments stored in a Jupyter notebook.

## Repository contents

- `N30_code_ck.ipynb` — main notebook containing the project experiments and implementation.

## How to explore

1. Clone or download this repository.
2. Open `N30_code_ck.ipynb` in JupyterLab, Jupyter Notebook, or VS Code with the Jupyter extension.
3. Inspect the notebook's imports, data paths, and model requirements before running cells.
4. Prepare the required dataset and dependencies referenced in the notebook.

## Notes

This is a notebook-based project, not a packaged application. Dataset availability, pretrained weights, exact dependency versions, and reproducibility have not been independently verified.
